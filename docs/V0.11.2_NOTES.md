# ZeroReels v0.11.2

This hotfix hardens ChatGPT browser readiness detection.

- Stops treating an inconclusive login-marker check as a fatal generation error.
- Waits for the actual ChatGPT message editor instead of failing after roughly one second.
- Supports current composer shapes including `#prompt-textarea`, contenteditable role=textbox, Lexical, ProseMirror, and textarea variants.
- Recognizes current account/profile controls as valid saved-session evidence.
- Keeps explicit login pages, login controls, and Cloudflare/human-verification gates as manual-user actions.
- Avoids immediately reloading ChatGPT during Test Session, allowing the current page to finish hydrating.
- Retries one clean ChatGPT navigation if the editor does not mount on the restored tab.
- Improves the final error message when ChatGPT loads but its editor remains unavailable.
